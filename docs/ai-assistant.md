# AI 班务助手（2.3.0）

## 管理员启用

使用系统管理员账号进入「AI 服务设置」，填写智谱开放平台 API Key，启用服务，点击「保存并测试连接」。模型固定为 `glm-4.6v-flash`，只调用智谱官方 HTTPS 接口。API Key 保存在服务器数据卷的 `ai-settings.json` 中（权限 600），不会返回到浏览器；留空保存保留旧密钥，勾选删除会停用服务。班干可以使用问答，只有系统管理员可以管理 API Key。

未配置时默认关闭。部署验证不会创建真实模型调用；启用后请实际测试一条文字问题和一张公告题目图片，确认账号的模型权限与视觉识别可用。

## 同学使用

1. 打开「AI 班务助手」，直接询问文件提交、问卷、扫码签到等系统操作。
2. 在通知公告详情点击「AI 解读 / 图片解题」，或在助手里点击「关联 / 导入公告」，关联最多 3 条公告。正文会随问题发送；勾选需要阅读的图片，合计最多 4 张。
3. 选择「公告解读」，询问报名入口、资格、材料、步骤、截止时间；选择「图片解题」，说明图片序号、题号，先核对识别的题干再查看讲解。
4. 外部公告可以粘贴文字、导入 UTF-8 TXT（40 KiB / 10000 字以内）或导入 JPG、PNG、WebP 截图。图片在浏览器压缩后发送，不发布到公告。PDF、Word 等附件请先提取文字或截取需要的页面。
5. 可以继续追问，回答中的公告来源可打开原文。变更参考资料时自动开始新对话，防止混用不同题目；刷新页面会清除对话。

AI 不会代为报名、提交文件或发送消息。未写明的报名信息应向主办方确认；不会主动访问公告中的链接或下载附件。回答可能有误，截止时间和办理结果以原公告、系统页面或主办方回执为准。

## 资源与限流

适用于单个 Uvicorn worker。默认全站同时处理 1 条、每人同时 1 条，每次间隔 5 秒；每人每分钟 3 次、滚动 24 小时 40 次；全站每分钟 12 次、滚动 24 小时 300 次。默认超时 60 秒、最多回答 2048 Token。管理员可以在限定范围内调整，并发最高 2；2 核 / 2 GiB 建议保持 1。

满载立即返回 503，达到额度返回 429 和 `Retry-After`，不排队、不自动重试。已开始但失败的请求和连接测试也计入限额；计数在内存中维护，服务重启后重置。智谱侧限流触发短暂全站冷却。增加进程或实例前必须改为共享限流器，不能直接横向扩容。

单次最多 4 张图片，每张 JPEG 不超过 160 KiB、最长边 1600 像素；复杂图片会进一步缩小，模糊时请裁剪题目区域。服务器本地图片缓存最多 32 张，解码串行进行；模型等待期间不占用数据库连接。文字、历史和模型响应均有长度上限，服务不存储对话，不记录问题或密钥。

AI 新增配置文件复用现有数据卷，不更改主数据库或签到数据库结构。发布时更新网页与后端版本为 2.3.0，不构建或替换 Android 安装包。
